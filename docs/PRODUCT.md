# 仕様と事業仮説

## 合意した大枠

- 顧客：忘年会、結婚式二次会、社内イベント等を開催する幹事。
- 参加者は無料。幹事がイベント単位で支払う。
- 価格：**1イベント2,980円（税込）**。ユーザーが2026-11-03に決定。
- 目標：決済手数料やサーバー等の直接経費控除後、税引前の月間利益10万円。収益の保証ではない。
- GitHub：publicな `cp-20/bingo`。
- 公開先：ロリポップ！デプロイナウ。
- Stripe：sandboxだけ。連携による参照は許可、本番データの参照やlive設定変更は対象外。

## 初版

無料プラン30人・7日間、有料プラン300人・30日間。1つのイベント内でリハーサルと複数ゲームを実施でき、自動更新しない。基本機能を無料で体験してから人数上限を解除する。初版ではAI司会、景品販売、当日有人サポートは作らない。

差別化の仮説は、簡単な作成から本番進行までの使いやすさ、抽選・カード状態の永続化、サーバー判定、景品管理、リハーサル、紙のバックアップ。これらは競合にもあるため、独自機能や支払意思が証明されたとは扱わない。

## 利益目標の試算

仮に決済費4%、固定費月3,000円、広告費ゼロとすると、2,980円×0.96×37件−3,000円＝**102,849.6円/月**。税金と自分の人件費は含まない。手数料4%と固定費3,000円は試算上の仮定であり、契約料金ではない。

37件は算術上の必要件数で、実際の需要予測ではない。仮に訪問から購入までの率が2%なら、月1,850件の見込み客の訪問が必要になるが、その購入率も未検証。忘年会等の季節変動を含め、実際のアクセス、イベント作成、参加、購入を計測して検証する。

初期の集客は会場・司会者・幹事への紹介と用途別の検索導線を想定する。自動営業や第三者へのメッセージ送信は行わない。広告出稿、ドメイン購入、有料プラン契約はまだ実施していない。
